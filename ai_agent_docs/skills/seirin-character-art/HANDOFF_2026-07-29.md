## 4. Tooling — use `tools/img_pipeline/`, not `tools/flatcel_finish.sh`

```bash
cd /home/user/Seirin/tools/img_pipeline
bash build.sh          # compiles upscale_filter + matte_floodfill (gcc -O2, few seconds)
bash run.sh <input_flat_white.png> <output_basename> [target_height=4096] [sharpen=0.6] [saturation=1.06] [white_threshold=14]
```

- Input **must** be the character on a genuinely solid `#FFFFFF`
  background (raw generator output), not an already-matted/transparent
  sprite.
- Pipeline order: `upscale_filter` (Catmull-Rom bicubic + unsharp + light
  saturation lift, on the still-opaque image) runs **first**, then
  `matte_floodfill` (real border-seeded BFS flood fill + 1px feather ring,
  at final resolution) runs **second**. This order matters — matting before
  upscaling reintroduces fringing, which is exactly the bug this pipeline
  replaced (see `tools/img_pipeline/GLSL_ATTEMPT_NOTES.md` and
  `ai_agent_docs/skills/seirin-character-art/_session_notes.md` for the
  full defect history).
- Verified this session: zero white-halo fringing at fine edges (hair,
  wrench), and WebP alpha matches PNG alpha bit-for-bit (`compare -metric
  AE` = 0 on `ren_normal_v3` — no dither/halftone noise from lossy WebP
  alpha requantization, which was the second defect the user caught).
- The user asked for a GLSL/GPU-shader upscaler instead of a CPU pipeline.
  This was attempted twice (headless Chromium+WebGL2 — confirmed working
  but heavyweight; then standalone SwiftShader EGL/GLES2 via `dlopen` — hit
  an ANGLE-routes-through-Vulkan initialization failure needing
  `VK_EXT_headless_surface`, unsupported in this sandbox). Full account in
  `tools/img_pipeline/GLSL_ATTEMPT_NOTES.md`. **Do not re-attempt this
  without reading that file first** — it records exactly which library
  symbols resolve, which EGL call fails, and why. If GPU upscaling is a
  hard requirement, the two next concrete options are recorded there. As
  shipped, `upscale_filter.c` runs the *identical math* a GLSL fragment
  shader would (same bicubic/unsharp/saturation formulas) as a plain C
  loop — same visual result, no GPU dependency.
- Binaries (`upscale_filter`, `matte_floodfill`) are gitignored — rebuild
  with `build.sh` each session; only the `.c`/`.h` sources are committed.
